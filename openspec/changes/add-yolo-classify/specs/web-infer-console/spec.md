## ADDED Requirements

### Requirement: 整图分类推理

推理页 SHALL 支持 YOLO 任务 `classify`。结果是整张图的一个类别和各类分数，不得绘制检测框。

#### Scenario: 单张分类结果

- **WHEN** 用户以分类 ONNX 和标签文件对一张图片推理
- **THEN** 界面必须显示得分最高的类别名、该类别分数，以及其余类别的分数
- **AND** 画面上不得出现检测框或框表

#### Scenario: 低于阈值

- **WHEN** 最高分类别的分数低于用户设置的置信度
- **THEN** 界面仍必须显示该类别
- **AND** 必须同时标明「不确定」

#### Scenario: 不接受引擎文件

- **WHEN** 用户对分类任务提交 `.engine`、`.trt` 或 `.plan`
- **THEN** 后端必须返回 400
- **AND** 说明必须指出分类引擎还没做，请改用 ONNX

#### Scenario: 输出对不上类别数

- **WHEN** ONNX 输出的最后一维与标签类别数不一致
- **THEN** 后端必须返回可读错误，不得把该输出当成检测框解析

#### Scenario: 隐藏不适用的参数

- **WHEN** 推理页任务选为分类
- **THEN** NMS 控件必须隐藏
- **AND** 置信度控件的说明必须改为「低于这个分数就显示不确定」
