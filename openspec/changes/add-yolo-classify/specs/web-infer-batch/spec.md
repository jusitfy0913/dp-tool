## ADDED Requirements

### Requirement: 批量与视频支持整图分类

目录批量、视频和摄像头 SHALL 支持 YOLO 分类任务。每张图或每一帧只有一个类别和分数，不得画检测框。

#### Scenario: 目录批量写出表格

- **WHEN** 分类批量任务正常结束
- **THEN** `results.csv` 必须为 `utf-8-sig` 编码
- **AND** 每一行必须包含文件名、类别、分数和是否不确定
- **AND** 不得要求生成画了检测框的标注图

#### Scenario: 视频每帧一个类别

- **WHEN** 用户对分类 ONNX 启动视频推理
- **THEN** 输出视频的每一帧必须只叠加一个类别名和分数
- **AND** 不得绘制检测框

#### Scenario: 摄像头每帧一个类别

- **WHEN** 客户端提交一帧摄像头图像做分类
- **THEN** 响应必须包含一个类别名和分数
- **AND** 不得包含检测框列表

#### Scenario: 批量任务拒绝引擎

- **WHEN** 分类批量、视频或摄像头请求使用 TensorRT 引擎
- **THEN** 后端必须拒绝并说明分类引擎还没做
