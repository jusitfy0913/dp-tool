### 联调中发现并修掉的两个问题

1. **「暂无图像」空态盖在图像上**
   `viewer.js` 用 `emptyEl.hidden = true` 隐藏空态，但 `.viewer-empty { display: grid }`
   的优先级高于 `[hidden]` 的浏览器默认样式，元素看起来还在。只有真跑一次推理才暴露。
   修法：在基础层加统一护栏 `[hidden] { display: none !important; }`，
   并删掉零散的 `.viewer[hidden]` 特例。
2. **控制台有一条 `/favicon.ico` 404**
   改为在 `index.html` 里内联 SVG 图标（data URI），不新增静态文件，404 消失。

### 关于「锚点漂移 0.5px」的澄清

早期手工测量得到 0.5px 级漂移，追查后确认是**测试脚本自身的问题**：
`MouseEvent.clientX` 在规范里是整数（`long`），脚本传了小数坐标被浏览器取整，
而测量端仍按小数算，于是每一步都差 0.1~0.5px。改用整数坐标后漂移降到 0.005px 以内。
这个坑记下来，避免以后又把测试缺陷当成产品缺陷去改代码。
