# Change: 重构 Web 工作站的视觉体系并新增可复用图像查看器

## Why

`6-web` 目前的样式基础无法支撑推理与标注这类以图像为中心的界面。实测现状：

- `6-web/frontend/css/style.css` 全文 **244 行**，只有 10 个颜色变量与 1 个圆角变量，**没有间距阶、字号阶、阴影层级**，所有间距靠散落的字面量。
- 只有 **1 个响应式断点**（`style.css:73` 的 `@media (max-width:1080px)`），窄屏下整页塌成单列。
- 图像显示是静态的：`.images img`（`style.css:178-186`）仅 `width:100%`，**没有任何缩放、平移能力**。一张 3034×1586 的 PCB 图缩到 600px 宽后，缺陷框只有几像素，现场根本无法用肉眼核验。
- 全前端无 `<canvas>`、无图表库、无设计变量化的字体与间距，视觉上仍是通用深色表单风，与工业检测场景的观感不符。

同时，后续两个变更（推理控制台、标注工作台）都需要同一套「可缩放、可平移、可开关」的图像窗口。若各自实现一遍，会出现两套手感不一致的代码。

## What Changes

- 重写 `6-web/frontend/css/style.css`，建立完整的设计令牌体系：
  - 颜色、间距阶（4/8/12/16/24/32）、字号阶、阴影层级、发光强度、动效时长全部变量化。
  - 配色改为工业赛博朋克风格：近黑底色、面板分层、主色青蓝、辅助品红、警示琥珀。
  - 背景使用纯 CSS 渐变绘制网格与扫描线，**不引入任何图片资源与第三方库**。
- 新增一组可复用组件类：切角发光面板、状态指示灯、仪表、滑块、数据表、指标卡、计时分解条。
- **新增 `6-web/frontend/js/viewer.js` 图像查看器组件**，作为本次变更的核心交付物：
  - 滚轮以**光标位置为锚点**缩放，倍率 0.1~20。
  - 左键拖动平移，使用 Pointer Events 与 `setPointerCapture`，拖出窗口不丢事件。
  - 双击复位；工具条提供适应窗口、1:1、放大、缩小与当前倍率。
  - 窗口可独立开关显隐，开关状态持久化。
  - 多窗口使用自适应网格布局，尽可能排在同一排。
- 建立可读性护栏：正文字号对比度不低于 WCAG AA（4.5:1）；日志区禁用闪烁类动效；尊重 `prefers-reduced-motion`。
- 只改样式与新增查看器组件，**不改动任何业务逻辑、接口与页面功能**。

## Impact

- 受影响能力：新增 `web-studio-theme` 能力。
- 受影响代码：
  - `6-web/frontend/css/style.css`（重写）
  - `6-web/frontend/js/viewer.js`（新增）
  - `6-web/frontend/index.html`（补类名与查看器容器，页面结构基本不变）
- 不受影响：`6-web/backend` 全部、两个 Python launcher、三个推理库、训练与引擎构建的功能逻辑。
- 后续依赖：`update-web-infer-console` 与 `add-web-annotation-workbench` 复用本变更的令牌与查看器，须在本变更完成后实施。
