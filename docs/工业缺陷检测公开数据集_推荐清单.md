# 工业缺陷检测公开数据集推荐清单

本文档汇总近年常用于论文与工程实践的**缺陷 / 表面异常**相关公开数据资源，**优先列出带标注**（目标框、像素级 mask、或官方评测用真值）的数据集，并区分**通用工业基准**与**偏专有行业**场景，便于按任务类型与行业选型。

> **说明**：各数据集以论文/官网说明为准；下载前请自行核对 **许可协议**（如是否允许商用、是否需申请）、**版本**与**引用格式**。

---

## 1. 文档用途

- 做**目标检测**（如 YOLO 系列）时，优先选带 **bbox** 或便于转框的标注。
- 做**无监督 / 少样本异常检测**时，优先 **MVTec** 及同类带 **测试集像素真值** 的基准。
- 做**语义/实例分割**时，选带 **mask** 或**像素级**标注的数据集。
- 需要**行业故事线**时，从第 4 节按行业挑选 1～2 个做验证或演示。

---

## 2. 较新或常用的通用 / 准通用基准

| 名称 | 标注概况 | 特点与适用 |
|------|----------|------------|
| **MVTec AD 2** | 公共测试子集含**像素级**真值；部分测试集为官方**私有**、无公开真值、需**线上评测** | 近年工业无监督异常检测新基准之一；场景含透明件、背光、微小缺陷等，难度高于经典 AD；适合与最新 SOTA 对比 |
| **MVTec AD** | 训练多为正常，测试含异常；**mask 真值**用于定位评估 | 异常检测领域使用最广的基准之一；算 AU-PRO、像素级 F1 等 |
| **MVTec LOCO AD** | 含**逻辑异常**（如缺件、关系错误）等设定 | 补充「外观正常但组合错误」类缺陷 |
| **VisA / MPDD / BTAD 等** | 多为**多场景**、常含 mask 或区域级标注（以各集说明为准） | 与 MVTec 交叉使用，看泛化与多品类 |

**检索关键词**：`MVTec AD 2`、arXiv `2503.21622`、`MVTec LOCO`、MVTec 公司 Research Datasets 页面；异常检测类库（如 Anomalib）中常有标准加载方式。

## 3. 经典仍常用的「带框」工业检测类

| 名称 | 标注概况 | 特点与适用 |
|------|----------|------------|
| **NEU-DET** | 水平框、多类表面缺陷 | 轧钢表面、论文与教学常用；适合作检测基线 |
| **GC10-DET 等** | 框、多类 | 与钢材/热轧等场景相关时参考 |

适合快速验证检测管线（训练/评估脚本与 mAP 流程）。

## 4. 按专有 / 强行业场景划分（带标注或明确评测设定）

| 行业方向 | 代表数据集/方向 | 标注与注意 |
|----------|------------------|------------|
| **铸造/金属机加工（表面）** | 如 CSDD 等近年铸造表面**检测与分割**基准 | 以论文/项目页为准；常面向气孔、夹杂等**铸造典型缺陷**；核对下载与许可 |
| **木器 / 家具涂装** | 如水性漆涂层木制品**表面缺陷**等（Scientific Data 等报道的公开数据） | 多类（划痕、气泡、孔洞等），**产线/工业相机关联**；核对作者提供的存储库与使用条款 |
| **PCB / 电子 SMT** | **DeepPCB** 等 | 常含**框或像素**（依子集不同）；与锡桥、少锡等**电子装联缺陷**强相关 |
| **冶金/钢材/带钢** | **NEU** 全系列、**Kaggle 钢材**等（若版本公开） | 锈蚀、刮伤、轧入氧化皮等；注意不同集为**分类**或**检测** |
| **纺织 / 织物** | **AITEX**、TILDA 等 | 多为**纹理缺陷**、mask 或图块；服装面料质检可类比 |
| **新能源（光伏等）** | **EL/可见光**电池片**裂纹、断栅**等公开集 | 以具体数据集卡为准，部分为**框或 mask**；行业属性强 |
| **轨道交通/基础设施** | **RSDD** 等（依公开版本） | **轨道/表面**类缺陷；标注形式需读该版本说明 |
| **小样本表面件** | **Kolektor、Magnetic Tile** 等 | 小区域、二值/区域标注等；**零部件表面**可类比 |

## 5. 任务类型快速选型

| 目标 | 建议优先看 |
|------|------------|
| 与无监督 / 异常检测 SOTA **对齐、发论文** | **MVTec AD 2** + **MVTec AD**（必要时 + LOCO、VisA） |
| 训练**通用两阶段/一阶段检测器** | **NEU-DET、GC10、DeepPCB** 及第 4 节中与业务接近的行业集 |
| 需要**行业场景**做演示/验证 | 第 4 节按**铸造/木业/PCB/纺织/光伏/轨交**各选 1 个 |
| 数据**极少**、偏异常检测 | **MVTec 系列** + 多场景集（**VisA** 等） |

## 6. 使用与工程注意

1. **许可**：学术常用「非商业」与「可商用」差异大，产品落库前需法务或商务确认。  
2. **划分**：无监督集不要误把测试异常图混入「训练正常」；有监督集注意**训练/验证/测试**与**类别平衡**。  
3. **评测**：MVTec AD 2 等可能含**私有测试集**，需通过**作者指定 benchmark** 对比官方榜单。  
4. **标注格式**：COCO、YOLO txt、mask PNG 等需自行转换时，以各集**官方或论文附录**为准。  
5. **链式/算法测试**（本仓库相关约定）：算子/推理链式验证宜以**框架与 API** 为主，具体见项目 `docs` 下其他工程说明。
